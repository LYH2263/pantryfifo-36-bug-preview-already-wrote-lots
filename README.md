# Pantryfifo · 冰箱临期先吃

分批入库 → FEFO 扣减 → 过期下架。

## 消费契约（先预演再确认）

- `POST /api/consume/preview`：只出预演票（将扣批号 + 数量）。总表、分层页、紧急条一律不动，余量不动。
- `POST /api/consume/confirm`：整单成功或整单失败，不按提交瞬间重算、不部分扣减。
  - 成功：实际扣减 == 预演数字，读回一致。
  - 失败（批被消费 / 过期扫走 / 余量不足）：票作废解除，所有余量保持预演前。
- 数量非正或非有限：直接 400，不留票。
